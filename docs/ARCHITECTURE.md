# 架构说明

> 骨架阶段：业务代码尚未落地。此处定义的是「仓库与智能体协作」的结构，业务架构确定后在本文件补充并同步 `AGENTS.md`。

## 逻辑分层

```text
使用者 / 智能体
      │  自然语言
      ▼
推理层：云端 LLM  ── 兜底 ── 本地 Ollama
      │  工具调用 / 命令行
      ▼
能力层：GitHub MCP Server  ── 兜底 ── gh CLI
      │
      ▼
数据层：本仓库（代码 + docs/ 知识源）
```

要点：

- **MCP 与 LLM 解耦**：任何一边不可用，都能用兜底路径继续工作。
- **仓库即知识源**：`AGENTS.md` 放约束，`docs/INTEGRATIONS.md` 放工具用法，`docs/AGENT-SETUP.md` 放接入方案；智能体遇事先查仓库，不依赖会话记忆。
- **凭据不入库**：`.env`、`mcp.local.json`、`*.pem` 全部被 `.gitignore` 排除；配置样例只放占位符。

## 仓库内各目录职责

| 目录 | 职责 | 变更门槛 |
| --- | --- | --- |
| `.github/` | 规则集落地的模板、工作流、责任人 | 需 platform-team 评审 |
| `docs/` | 架构 / 集成 / 治理 / 接入文档 | 需 docs-team 评审 |
| `config/` | 配置样例（可入库） | 需 platform-team 评审 |
| `src/` `tests/` | 业务代码与测试 | 常规 PR |
